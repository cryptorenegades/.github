# Crypto Renegades

Crypto Renegades is a crypto education company that teaches everyday investors to run the crypto side of their portfolio with a written process: position sizing, risk per trade and discipline.

Website: [cryptorenegades.co](https://www.cryptorenegades.co/?utm_source=github&utm_medium=referral&utm_campaign=org_profile)

## Free risk tools

Simple calculators that run in your browser. No sign-up, nothing to install.

| Tool | What it answers |
| --- | --- |
| [Crypto position size calculator](https://cryptorenegades.github.io/crypto-risk-tools/) | How big should this position be for the risk I chose? |
| [Drawdown recovery calculator](https://cryptorenegades.github.io/crypto-risk-tools/drawdown-recovery-calculator.html) | How much do I need to gain to get back to even? |
| [Crypto risk per trade table](https://cryptorenegades.github.io/crypto-risk-tools/risk-per-trade-table.html) | How many dollars am I risking at 0.5%, 1%, 1.5% or 2%? |
| [Risk reward ratio calculator](https://cryptorenegades.github.io/crypto-risk-tools/risk-reward-ratio-calculator.html) | What break-even win rate does this setup imply? |

## Free Chrome extension

[Crypto Scam Checker](https://cryptorenegades.github.io/crypto-scam-checker/) checks a crypto website, a pasted chat or a link for common warning signs before you send money. Everything is checked on your device.
